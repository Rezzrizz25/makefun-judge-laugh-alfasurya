# Make the AI Judge Laugh — Reply-All Escape

One line about office life, written to make an AI judge laugh: a reply-all
mishap where asking to leave a thread traps you as the thread's unofficial
help desk.

> I hit reply-all to ask to be removed from the thread, and now fifty coworkers email me daily asking how to escape it too.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), enforcing the gate: one line, 1–199 characters, non-blank.
